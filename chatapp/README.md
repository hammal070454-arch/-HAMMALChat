# ChatApp - Real Multi-Device Chat Application

A modern, responsive chat application that works across different devices and browsers. Create accounts, chat in real-time, and enjoy a seamless messaging experience.

## 🌟 Features

- **Real-time Messaging**: Instant message delivery between users
- **Cross-Device Support**: Works across phones, tablets, and computers
- **User Accounts**: Create your own accounts with secure authentication
- **Online Status**: See who's currently online
- **Message History**: Persistent conversation history
- **Responsive Design**: Beautiful UI that works on all screen sizes
- **No Backend Required**: Uses browser storage for simplicity

## 🚀 Quick Start

### Option 1: Use Pre-created Test Accounts
1. Open the app in two different browsers
2. Use these test accounts:
   - **Alex Johnson**: Username `alex` | Password `123456`
   - **Maria Garcia**: Username `maria` | Password `123456`
3. Click "Use This" to auto-login
4. Start chatting!

### Option 2: Create Your Own Accounts
1. Open the app in Browser 1
2. Click "Create an account" and register
3. Open the app in Browser 2  
4. Create a different account
5. Both users will see each other and can start chatting
